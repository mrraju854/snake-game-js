# 🐍 Snake Game

A responsive Snake Game built using HTML, CSS, and JavaScript.

## 🚀 Features
- Smooth gameplay
- Score & High Score system
- Mobile-friendly controls
- Clean UI with animations

## 🎮 How to Play
- Use arrow keys or on-screen buttons
- Eat food to grow
- Avoid walls and yourself
